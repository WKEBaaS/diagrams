BaaS 平台資料庫 Schema 架構圖

auth Schema
身份認證核心 (Better-Auth)
此區域專門供 better-auth 套件使用，負責處理所有與使用者身份驗證相關的流程與資料儲存。

主要用途：
  • 受 better-auth 管理的使用者資料表
  • Session 與 Account Link 管理
  • 提供安全的身份驗證基礎設施
Powered by better-auth
dbo Schema
I3S 核心業務邏輯
BaaS 平台的資料核心，實作 I3S 架構。透過彈性的 Class-Object 結構儲存專案業務資料，並包含權限控制表。

主要用途：
  • 彈性化資料模型 (Classes, Objects)
  • 權限控制 (Permissions)
  • 專案核心業務資料
Core Business Data
api Schema
PostgREST 自動映射層
BaaS 透過 PostgREST 將此 Schema 中的函式 (Functions) 自動轉換為 RESTful API。配合 Valibot 與 JWT，實現高效且安全的端點呼叫。

主要機制：
  • Function 即 API：自動對應為 API 端點
  • Runtime 安全：整合 Valibot 驗證輸入/輸出
  • 權限整合：解析 JWT 並切換資料庫角色
Functions to Endpoints
